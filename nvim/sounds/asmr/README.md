# :ASMR keyboard sounds

Real switch recordings from kbsim by Thomas Lai — https://github.com/tplai/kbsim
(commit ba103f3, `src/assets/audio/`). Only the press sounds are used; each clip was
converted to WAV, trimmed to start 1 ms before the hit, and peak-normalized to 0.7 so
all five sets play at the same volume.

| :ASMR | Folder | Switch          | kbsim pack |
|-------|--------|-----------------|------------|
| 1     | 1/     | NK Cream        | cream      |
| 2     | 2/     | Kailh Box Navy  | boxnavy    |
| 3     | 3/     | Holy Panda      | holypanda  |
| 4     | 4/     | Buckling spring | buckling   |
| 5     | 5/     | Topre           | topre      |

Files: `key1-5.wav` (regular keys, picked at random), `space.wav`, `enter.wav`, `backspace.wav`.
